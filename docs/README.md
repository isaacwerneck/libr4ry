## Como manter estes documentos

O README da raiz apresenta o projeto e o caminho de início. Instruções de uso ficam no guia; configuração técnica, no documento de desenvolvimento. Novas decisões atualizam contexto, requisitos ou design conforme o assunto. Relatos de implementação e resultados de testes ficam no histórico e no andamento, sem acumular detalhes no README principal.

A reorganização de 12/10/2026 preservou o histórico anterior, centralizou o contexto nesta pasta e separou uso de configuração. `context.md` na raiz permanece como referência para ferramentas de desenvolvimento. Materiais de estudo em `content/` e instruções das skills em `skills/` conservam suas próprias finalidades.
